# Lessons

---

## A profile page is prose about work that keeps moving

Every other page in this estate describes something in the same repository, so it goes
stale with a diff somebody can see. A profile page describes repositories that change
after it is written, and nothing in it moves when they do. The command gets renamed, the
gate gets renumbered, the artifact moves, and the page goes on saying what was true.

That is why every card names a path and the checks resolve it, and why they run on a
schedule rather than only on a push to this repository. The push that breaks a card is
almost never a push to this repository.

## Reading the set from the account is the difference between a check and a list

The first shape of the card check compared the cards against a list of repositories kept
in this repository. That is two copies of one fact and the second one rots: the day a
repository goes public, the list still says it is not. Reading the set from the account
means a repository going public with no card is a gap the check finds.

## "No unbound superlative" has a simpler honest reading

Trying to decide whether a given superlative is bound needs a judgement the check cannot
make. There is no file that proves "best", so the vocabulary is refused outright and the
card says what the repository does instead.
